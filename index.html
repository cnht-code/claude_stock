Apps Script — Hướng dẫn cài đặt

✅ Script v5 — proxy giá TCBS qua server Google, không bị CORS block.

BƯỚC 1 — Lần đầu deploy:

  1. Mở Google Sheets mới → Extensions → Apps Script
  2. Xoá hết code cũ → nhấn "Copy Script Code" bên dưới → Paste vào
  3. Deploy → New deployment → Web app
  4. Execute as: Me | Access: Anyone → Deploy
  5. Nhấn Authorize access (chọn tài khoản Google → Allow)
  6. Copy Web app URL → Dán vào Cài đặt → Google Apps Script

BƯỚC 2 — Cập nhật code (giữ URL cũ):

  1. Mở lại Apps Script → xoá hết → paste code mới
  2. Deploy → Manage deployments → ✏️ Edit → New version → Deploy
