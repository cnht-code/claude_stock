Hướng dẫn cài đặt Google Sheets

Cài đặt lần đầu — sau này cập nhật code KHÔNG tạo lại:

  1. Mở Google Sheets → tạo spreadsheet mới
  2. Vào Extensions → Apps Script
  3. Xoá hết code cũ → nhấn "Copy Script Code" bên dưới → Dán vào
  4. Nhấn Deploy → New deployment
  5. Chọn type: Web app | Execute as: Me | Who has access: Anyone
  6. Nhấn Deploy → Authorize access
  7. Copy Web app URL → Dán vào ô URL bên dưới → Lưu
⚠️ Quan trọng: URL chỉ tạo 1 lần duy nhất. Mỗi lần thay đổi code sau này dùng tab "Cập nhật code" để giữ nguyên URL.

Cập nhật code mà không đổi URL:

  1. Mở lại file Apps Script (từ Spreadsheet → Extensions → Apps Script)
  2. Xoá hết code cũ → Dán code mới từ nút bên dưới
  3. Nhấn Deploy → Manage deployments
  4. Nhấn biểu tượng ✏️ Edit (cây bút) trên deployment hiện tại
  5. Ở mục Version, chọn "New version" (không phải tạo deployment mới)
  6. Nhấn Deploy — URL giữ nguyên ✅
✅ URL không thay đổi, không cần cập nhật trong ứng dụng.
