Hướng dẫn cài đặt Google Sheets

Làm theo các bước sau để lưu dữ liệu vào Google Sheets miễn phí, không cần API key:

  1. Mở Google Sheets → tạo spreadsheet mới, đặt tên tuỳ ý
  2. Trong spreadsheet: Extensions → Apps Script
  3. Xoá code cũ, dán toàn bộ nội dung script bên dưới vào
  4. Nhấn Deploy → New deployment → Web app
  5. Execute as: Me | Who has access: Anyone → Deploy
  6. Copy Web app URL → dán vào Cài đặt → Apps Script URL
  7. Lần đầu sẽ hỏi quyền → nhấn Authorize access
